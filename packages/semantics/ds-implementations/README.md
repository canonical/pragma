# @canonical/ds-implementations

Turtle (RDF) datasets describing the implementation libraries and
implementations of the Canonical design system, generated from `@implements`
annotations across the pragma monorepo.

The canonical data lives at the monorepo root `data/` directory and is
regenerated by `bun run collect` (see `scripts/collect-implementations.ts`).
This package snapshots that data at publish time (`prepack`) so it can be
consumed as a pragma pack:

- `data/implementations.ttl` — aggregate index of all implementation libraries
- `data/{librarySlug}/implementationLibrary.ttl` — one `ds:ImplementationLibrary` per library
- `data/{librarySlug}/implementationObjects.ttl` — the library's `ds:ImplementationObject`s

Each implementation carries a `ds:headLink` (source at `main`) and a
`ds:versionedLink` (source pinned to the release tag), and each library a
`ds:version` matching the release that produced it.

The vocabulary is the `ds:` ontology defined by `@canonical/design-system`.
